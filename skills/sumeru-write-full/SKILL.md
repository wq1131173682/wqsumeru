### 一、完整示例对比

**场景：** 主角第一次在公开场合使用金手指

#### 机械写法

> 主角深吸一口气，走上台。
> 对手冷笑："就你？"
> 主角抬手，一道光芒射出。
> 对手倒地，全场震惊。
> 主角赢了。

#### 人性化写法

> 主角走上台时，手心全是汗。
> 他下意识摸了摸鼻子——这是紧张时的老毛病。
> 
> 对手冷笑："就你？"
> 主角没说话。
> 他想说点什么，喉咙却发紧。
> 
> （停顿）
> 
> 算了，直接上吧。
> 
> 抬手，光芒射出。
> 比想象中快。
> 
> 对手倒地。
> 全场安静了一秒，然后炸了。
> 
> 主角站在原地，没欢呼。
> 只是觉得...腿有点软。
> 原来真赢了。

#### 对比分析

| 元素 | 机械写法 | 人性化写法 |
|------|----------|-----------|
| 身体反应 | 无 | 手心出汗、摸鼻子、腿软 |
| 对话 | 完整清晰 | 有停顿、想说却说不出 |
| 情绪 | "赢了" | "原来真赢了"（意外感） |
| 人物习惯 | 无 | 摸鼻子（紧张时） |
| 节奏 | 平铺直叙 | 有停顿、有留白 |

**关键差异：**
- 机械写法：只传达了"发生了什么"
- 人性化写法：传达了"人物感受到了什么"

### 二、详细自检清单

```markdown
## 人性化自检（完整版）

### 人物
- [ ] 有没有添加人物小习惯（紧张/思考/情绪波动时）
- [ ] 人物行为是否符合性格（没有 OOC）
- [ ] 人物有没有意外但合理的选择
- [ ] 人物小习惯是否本章只出现 1 次（避免套路化）

### 对话
- [ ] 对话有没有停顿、口误、打断
- [ ] 对话是不是太"完美"（每句都清晰完整）
- [ ] 对话有没有潜台词（言外之意）
- [ ] 对话是否符合人物性格（不是千人一面）

### 情绪
- [ ] 情绪是不是单一（如只有狂喜）
- [ ] 有没有情绪层次（如"又开心又空虚"）
- [ ] 是不是用身体反应展现情绪（不是直接说）
- [ ] 情绪是否符合场景触发条件（见核心层）

### 场景
- [ ] 有没有与主线无关但增加真实感的细节
- [ ] 细节是不是堆砌（超过 2 个就要删减）
- [ ] 细节有没有功能（暗示人物状态/推动情绪）
- [ ] 细节是否符合场景触发条件

### 整体
- [ ] 毛边有没有偏离主线 purpose
- [ ] 毛边是不是套路化（如每次紧张都摸鼻子）
- [ ] 读者会不会觉得"这人物是活的"
- [ ] 本章是否有 1 个读者能记住的瞬间
```

### 三、毛边使用示例库

> 完整示例库见 `sumeru-write/references/rough-edge-examples.md`，包含 3 个场景：
> - **紧张场景**：摸鼻子 + 手心出汗 + 对话停顿
> - **胜利场景**：腿软 + 胜利后空虚
> - **情感场景**：对话停顿 + 没说出口的话

---

### 四、模式使用建议

| 场景 | 推荐模式 | 原因 |
|------|----------|------|
| 过渡章/日常章 | `light` | 不需要太多毛边，保证节奏 |
| 人物互动章 | `medium` | 需要展现人物深度 |
| 情感章 | `medium` 或 `full` | 需要情绪层次和细节 |
| 高潮章 | `light` 或 `medium` | 严格控制，避免偏离 |
| 人物塑造章 | `full` | 需要完整示例参考 |
| 首次公开场合 | `full` | 需要参考示例 |
