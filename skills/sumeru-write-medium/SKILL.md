## 已废弃：Medium 增量

> ⚠️ 本 Skill 已废弃。`sumeru-write` 现在只使用一种通用写作模式，不再区分 `light`/`medium`/`full`。

以下内容仅作为历史参考。需要的人物真实感、毛边类型和自检规则应合并维护到 `sumeru-write-core`。

---

### 一、人性化核心表格

#### 机械写法 vs 人性化写法对比

| 类型 | AI 机械生成 | 人性化毛边 |
|------|------------|-----------|
| **人物习惯** | 完美执行任务 | 紧张时摸鼻子、思考时转笔 |
| **对话** | 每句都清晰完整 | 有停顿、口误、重复、打断 |
| **情绪** | 单一情绪（如狂喜） | 胜利后的空虚、悲伤后的麻木 |
| **选择** | 最优解 | 意外但合理的非最优选择 |
| **场景** | 功能性描写 | 注意到对方手上的老茧 |

---

### 二、毛边类型速查

#### 1. 人物小习惯（每人物 1-2 个即可）

```markdown
# 在 context pack 中查找人物小习惯

## Character Quirks
- 主角：紧张时摸鼻子（第 5 章首次出现）
- 女配苏瑾：思考时转笔（第 12 章首次出现）
- 反派赵无极：说话时喜欢转茶杯（第 8 章首次出现）

# 写作时：
- 在紧张/思考/情绪波动时自然加入
- 不要每次都用，偶尔出现才有存在感
- 可以随人物成长变化（如后期不再摸鼻子，说明变自信了）
```

#### 2. 对话真实感

```markdown
# 好的对话

"我...我不是这个意思。"（停顿）
"我是说...算了，你懂吧。"（改口）

"你——"（正要说什么，被对方打断）
"行了，我知道你要说什么。"

# 坏的对话

"我不是这个意思，我的意思是..."（过于清晰完整）
"你说得对，我确实错了。"（像背台词）

# 技巧
- 允许角色说一半改口
- 允许角色被情绪打断
- 允许角色词不达意（真实人就是这样）
- 但确保读者能理解核心意思
```

#### 3. 情绪层次

```markdown
# 单一情绪（机械）
主角赢了，他感到非常开心。

# 情绪层次（人性化）
主角赢了。
他本该狂喜的——毕竟等了三年。
可当对手倒下时，他只觉得...累。
原来赢了也就这样。

# 技巧
- 不要直接说"开心/悲伤/愤怒"
- 用身体反应、环境对比、内心独白展现
- 允许矛盾情绪共存（如"又开心又空虚"）
```

#### 4. 意外但合理的选择

```markdown
# 预期选择（套路）
主角被挑衅 → 立刻打脸

# 意外选择（毛边）
主角被挑衅 → 沉默，转身离开
（读者：？？？）
下一章：主角在角落研究对手招式
（原来他在憋大招）

# 技巧
- 选择必须符合人物性格（内向的人不会突然社牛）
- 选择必须有后续解释（不能为了意外而意外）
- 选择最好有伏笔（前文提到过类似倾向）
```

#### 5. 场景细节

```markdown
# 功能性描写（机械）
两人在茶馆见面，讨论计划。

# 细节描写（人性化）
茶馆里人声嘈杂。
主角选了个角落，背对墙壁——这是老习惯。
对面的人迟到了三分钟，进门时抖了抖伞上的雨。
"抱歉，路上堵。"
主角没说话，只是把茶推过去。
茶已经凉了。

# 技巧
- 选 1-2 个细节即可，不要堆砌
- 细节最好有功能（如"背对墙壁"暗示警惕）
- 细节可以暗示人物状态（如"茶凉了"暗示等待时间）
```
