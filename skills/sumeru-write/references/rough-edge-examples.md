# 毛边使用示例库

> 本文件供 `sumeru-write-full` 增量层引用，包含 3 个场景的毛边使用完整示例。

## 示例 1：紧张场景

```markdown
# 场景：主角第一次面对强敌

# 触发条件检查：
- 摸鼻子：社交压力 ✓ + 内心紧张 ✓ + 本章未使用 ✓ → 可以添加
- 手心出汗：重大决策 ✓ + 首次公开 ✓ → 可以添加
- 腿软：战斗后？❌ → 不触发（战斗未开始）

# 写作：
> 他走上擂台时，手心全是汗。
> 下意识摸了摸鼻子——这是紧张时的老毛病。
> 
> 对手比他高半个头，眼神像看死人。
> 主角咽了口唾沫，喉咙发紧。
> 
> （这里可以加对话停顿）
> "请...请指教。"
```

## 示例 2：胜利场景

```markdown
# 场景：主角历经 3 章苦战，终于击败强敌

# 触发条件检查：
- 胜利后的空虚：期待 3 章以上 ✓ + 付出重大代价 ✓ + 独自一人？→ 看场景
- 腿软：战斗后 ✓ → 可以添加
- 摸鼻子：社交压力？❌ → 不触发（战斗场景）

# 写作：
> 对手倒下了。
> 全场安静了一秒，然后炸了。
> 
> 欢呼声像潮水一样涌来。
> 主角站在原地，没动。
> 
> 腿有点软。
> 他扶着擂台边缘，才站稳。
> 
> 赢了。
> 可心里...空落落的。
> 原来赢了也就这样。
> 
> （注意：这里没有添加"狂喜"，因为代价太大）
```

## 示例 3：情感场景

```markdown
# 场景：主角与重要人物告别

# 触发条件检查：
- 对话停顿：情绪波动强烈 ✓ → 可以添加
- 手心出汗：重大决策？❌ → 不触发（情感场景）
- 转笔：独自思考？❌ → 不触发（两人在对话）

# 写作：
> "你...你真的要走吗？"
> 她的声音有点抖。
> 
> 主角没看她的眼睛。
> "嗯。"
> 
> （停顿）
> 
> "那...一路保重。"
> "你也是。"
> 
> 他想说点什么，喉咙却发紧。
> 算了，不说也罢。
> 
> 转身，离开。
> 没回头。
> 
> （注意：这里用"没说出口的话"代替"说出口的话"，更有张力）
```
