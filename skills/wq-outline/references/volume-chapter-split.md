# 卷→章自动拆分参考模板

> 子Agent 生成章节细纲时的拆分算法参考。将一卷大纲的描述性内容，按本模板拆解为 N 章可执行的章节任务卡。

---

## 一、章数确定决策树

### 1.1 按字数倒推

```
plannedWords = project.json.plannedWords
chapterWordRange = project.json.chapterWordRange  // 如 [2000, 3000]
totalVolumes = outline.md 中的分卷数

roughChaptersPerVolume = ceil(plannedWords / totalVolumes / avg(chapterWordRange))
```

**示例**：80 万字、3000 字/章、4 卷 → `800000 / 4 / 2500 = 80 章/卷` → 卷太长，需调整卷数或章节字数范围。

### 1.2 按卷类型调整系数

| 卷类型 | 系数 | 说明 |
|--------|------|------|
| 开篇卷 | ×1.2 | 需建立世界观、引入人物，比平均多 20% 篇幅 |
| 发展卷 | ×1.0 | 标准推进 |
| 过渡卷 | ×0.8 | 承上启下，篇幅可略短 |
| 高潮卷 | ×1.3 | 多线交汇、大场面，篇幅最大 |
| 转折卷 | ×1.1 | 关键反转、人物蜕变，需充分铺垫 |
| 收束卷 | ×1.0 | 结局收尾，按标准篇幅 |

### 1.3 按卷内核心事件数锚定保底

```
minChapters = count(coreEvents) + count(subplots climax in this volume)
```

至少保证：每个核心事件 ≥ 1 章展开、每条支线的卷内高潮 ≥ 1 章。

**最终章数**：取 `max(字数倒推 × 系数, 事件锚定保底)`，再根据节奏需求微调（±1 章）。

---

## 二、章节边界确定规则

### 2.1 一章节 = 一个完整情绪节拍

每章承载一个完整的 A-G 情绪模板。不是所有情绪模板步长相同：

| 模板 | 典型章数 | 说明 |
|------|----------|------|
| A 反转型 | 1 章 | 期待→落空→意外→爆发，一口气读完，不分章 |
| B 递进型 | 2-3 章 | 平静→波动→升级→爆发，可在"波动→升级"处分章 |
| C 抑扬型 | 2-3 章 | 低谷→挣扎→转机→希望，在"挣扎→转机"处分章 |
| D 双线型 | 2-3 章 | A 线+B 线→交汇→引爆，在"A 线+B 线→交汇"处分章 |
| E 悬念型 | 1-2 章 | 异常→试探→揭示→未知，在"试探→揭示"处分章 |
| F 情绪型 | 1-2 章 | 抵触→触动→接纳→升温，一情绪场景一章节 |
| G 低谷型 | 2-3 章 | 压制→崩溃边缘→觉醒→反击，在"崩溃边缘→觉醒"处分章 |

### 2.2 章节结尾 = 钩子

每章结尾必须有一个钩子（悬念/反转/新问题），这是强制性的章节边界信号：

| 钩子类型 | 适用场景 | 示例 |
|----------|----------|------|
| **信息钩子** | 悬念型/反转型 | "门推开的那一刻，他看到了一个绝不可能出现在这里的人——" |
| **决策钩子** | 递进型/抑扬型 | "他手里握着那颗丹药，服下去可能突破，也可能经脉寸断。" |
| **冲突钩子** | 战斗/追逐场景 | "剑锋已到眼前，而他手中没有武器。" |
| **情感钩子** | 情绪型/低谷型 | "她看着他离去的背影，突然发现自己不知道他还会不会回来。" |

> **章节边界判断法则**：如果当前场景结束后，找不到一个自然的钩子 → 不要在此处分章，继续推进直到钩子出现。

### 2.3 不准在以下位置分章

- ❌ 战斗打到一半（除非是"前一章结尾被击中，下一章开头揭晓结果"的悬念式分章）
- ❌ 对话正在进行中且无信息断点
- ❌ 情绪转折的半途（如"压抑→挣扎"之间，应让挣扎铺满一章）
- ❌ 纯设定交代中（应把设定嵌入章节，不单独成章）

## 三、按卷类型的分章模板

### 模板 A：开篇卷

**特征**：建立世界观、引入主角、第一个冲突触发、金手指/系统觉醒（如有）

**标准章分配**（假设 10 章）：

| 章节 | 功能 | 情绪模板 | 节奏 |
|------|------|----------|------|
| 001 | 主角日常 + 困境展示 + 个性锚点 | F（抵触→触动）或 E（异常→试探） | medium |
| 002 | 触发事件（变故/穿越/觉醒） | A（期待→落空→意外） | fast |
| 003-004 | 新世界/新规则建立 + 生存冲突 | B（平静→波动→升级） | medium→fast |
| 005 | 第一个支线/人物出场 | D（双线引入） | medium |
| 006-007 | 成长/适应 + 第一个小高潮 | C（低谷→挣扎→转机） | slow→medium |
| 008 | 阶段性小BOSS 或考验 | A（反转型） | fast |
| 009 | 战果展示 + 新目标确立 | B（升级→爆发→新目标） | medium |
| 010 | 卷末悬念/新势力/新地图预告 | E（悬念型） | medium→slow |

### 模板 B：发展卷

**特征**：主角实力提升、世界观扩展、支线展开、势力登场

**标准章分配**（假设 8 章）：

| 章节 | 功能 | 情绪模板 | 节奏 |
|------|------|----------|------|
| 001 | 承接上卷 + 当前任务/目标重申 | F（触动→接纳）或 D（双线收束） | medium |
| 002-003 | 修炼/探索/势力接触 | B（平静→波动→升级） | medium→fast |
| 004 | 支线事件触发 | E（异常→试探） | medium |
| 005 | 冲突升级/遭遇战 | A（期待→落空→意外） | fast |
| 006 | 低谷/损失/代价 | G（压制→崩溃边缘） | slow |
| 007 | 反弹 + 阶段性胜利 | C（转机→希望） | medium→fast |
| 008 | 卷末反转/新谜题/下卷预告 | A 或 E | fast/medium |

### 模板 C：过渡卷

**特征**：承上启下、信息铺垫、人物关系深化、暴风雨前的宁静

**标准章分配**（假设 5 章）：

| 章节 | 功能 | 情绪模板 | 节奏 |
|------|------|----------|------|
| 001 | 消化上卷结果 + 新方向确立 | F（抵触→接纳） | slow |
| 002 | 信息获取/关键人物对话 | D（双线交汇） | medium |
| 003 | 日常中的异常信号（伏笔铺设） | E（异常→试探→揭示） | medium |
| 004 | 关系升温/团队建设/暗流涌动 | F（触动→接纳→升温） | slow→medium |
| 005 | 危机前兆 + 新变数插入 | E（揭示→新的未知） | medium→fast |

### 模板 D：高潮卷

**特征**：多线交汇、大场面、高冲突、密集爽点

**标准章分配**（假设 10 章）：

| 章节 | 功能 | 情绪模板 | 节奏 |
|------|------|----------|------|
| 001-002 | 蓄力阶段：集结/备战/最后准备 | B（平静→波动→升级） | medium→fast |
| 003 | 冲突触发 + 第一波交锋 | A（期待→落空→意外） | fast |
| 004 | 混战/多线并进 | D（双线型） | fast |
| 005 | 主角的抉择时刻/代价付出 | C（低谷→挣扎→转机） | medium |
| 006 | 反派的反击/意外变数 | G（压制→崩溃边缘→觉醒） | fast |
| 007 | 第二波高潮/底牌亮出 | A（反转型） | fast |
| 008 | 惨胜/损失/情绪消化 | C（低谷→希望） | slow→medium |
| 009 | 敌人阴谋浮出水面/更大危机 | E（悬念型） | medium |
| 010 | 卷末余韵 + 下卷方向 | F（接纳→升温） | slow→medium |

### 模板 E：转折卷

**特征**：重大反转、人物蜕变、真相揭露、阵营转换

**标准章分配**（假设 8 章）：

| 章节 | 功能 | 情绪模板 | 节奏 |
|------|------|----------|------|
| 001 | 暴风雨前的假象/反常平静 | E（异常→试探） | slow |
| 002 | 反转触发（背叛/真相/陷阱） | A（落空→意外→爆发） | fast |
| 003 | 主角的崩溃/信念动摇 | G（压制→崩溃边缘） | slow |
| 004 | 重新站起/抉择 | C（转机→希望） | medium |
| 005 | 新方向/新同伴/新力量 | F（抵触→触动→接纳） | medium |
| 006 | 目标调整 + 计划制定 | B（平静→波动→升级） | medium |
| 007 | 第一次在新方向上的行动 | A（期待→意外） | fast |
| 008 | 卷末局势重塑 + 新悬念 | D（双线交汇→引爆） | fast |

### 模板 F：收束卷

**特征**：最终冲突、全局回收、结局呈现、尾声余韵

**标准章分配**（假设 8 章）：

| 章节 | 功能 | 情绪模板 | 节奏 |
|------|------|----------|------|
| 001 | 最终战前态势梳理 + 全员就位 | D（多线交汇） | medium |
| 002-003 | 最终战起手 + 最高冲突 | B（升级→爆发） | fast |
| 004 | 终极反转/最大秘密揭示 | A（反转型） | fast |
| 005 | 最高牺牲/代价/告别 | G（崩溃边缘→觉醒） | slow |
| 006 | 决战终局 | A 或 B | fast |
| 007 | 结局呈现 + 情感收束 | C（转机→希望）或 F（接纳→升温） | medium |
| 008 | 尾声 + 开放式/闭合式结尾 | F 或 C | slow |

## 四、场景密度与章节字数指导

### 4.1 每章场景数

| 节奏 | 场景数 | 说明 |
|------|--------|------|
| fast | 2-3 个场景 | 场景切换快，对话和动作主导 |
| medium | 2-4 个场景 | 标准节奏，叙述+描写+对话均衡 |
| slow | 1-2 个场景 | 场景纵深大，环境和心理描写多 |

### 4.2 章节字数锚点

按平台类型确定每章字数范围：

| 平台 | 每章字数 | 说明 |
|------|----------|------|
| 番茄 | 2000-3000 | 节奏快、信息密度高 |
| 七猫 | 2000-3000 | 同上 |
| 起点 | 2500-4000 | 适度描写和铺垫 |
| 晋江 | 3000-5000 | 心理和情感描写更细致 |
| 纵横 | 2500-3500 | 标准网文字数 |

## 五、拆分前必须检查的资源约束

在执行拆分前，子Agent 必须从 `wq-rules/SKILL.md` 已定义规则中确认以下约束：

### 5.1 情绪模板轮换约束

连续 3 章不得使用同一模板。拆分时需按此规则预分配模板 ID。

**分配策略**：
1. 先根据卷类型确定本卷的模板序列（参考第三部分各模板）
2. 检查与上一卷最后 2 章的模板是否违规
3. 若有连续 3 章相同 → 交换中间章的模板（确保场景合适）
4. 卷首章优先 B 或 D，卷尾章优先 A 或 C

### 5.2 节奏交替约束

```
fast: 30-40% | medium: 40-50% | slow: 10-20%
连续 2 章 fast → 必须插入 medium/slow
连续 3 章 slow → 上限
```

拆分完成后统计本卷节奏比例，不符合时调整局部章节节奏标记。

### 5.3 开场方式多样性约束

同一批次（连续 3-4 章）开场方式不得雷同。卷首章不得用"被叫醒""从床上醒来"模板。

## 六、拆分规划表（子Agent 输出模板）

子Agent 在生成 `chapters.json` 前，先用此表格规划分章方案，确保逻辑完整性：

```markdown
## 分卷拆分规划：第X卷「卷名」

### 基本信息
| 项目 | 值 |
|------|-----|
| 卷类型 | 开篇/发展/过渡/高潮/转折/收束 |
| 总章数 | N |
| 本卷字数范围 | N * [wordPerChapterMin, wordPerChapterMax] |
| 核心事件数 | M |
| 支线在本卷的高潮 | P 条 |

### 章序规划
| 章号 | 情绪模板 | 节奏 | 核心事件 | 卷内功能 | 开场方式（简记） |
|------|----------|------|----------|----------|-----------------|
| 001 | B | medium | 承接上卷+新方向 | 过渡衔接 | 闪回/环境切入 |
| 002 | C | slow | 主角面临选择 | 低谷铺垫 | 对话切入 |
| 003 | A | fast | 冲突爆发 | 卷内高潮 | 动作切入 |
| ... | ... | ... | ... | ... | ... |

### 约束合规检查
| 检查项 | 结果 |
|--------|------|
| 连续 3 章模板不重复 | ✅/⚠️ |
| fast 比例在 30-40% | ✅/⚠️（当前 X%） |
| medium 比例在 40-50% | ✅/⚠️（当前 X%） |
| slow 比例在 10-20% | ✅/⚠️（当前 X%） |
| 无连续 3 章 slow | ✅/⚠️ |
| 连续 2 章 fast 后非 slow | ✅/⚠️ |
| 开场方式不雷同 | ✅/⚠️ |
| 卷首章非 A/G | ✅/⚠️ |
| 卷尾章非 F/G | ✅/⚠️ |
| 本卷模板与上卷末尾 2 章不构成 3 连 | ✅/⚠️ |
```

然后依据此规划表生成 `outlines/chapters.json` 的每章任务卡。

## 七、常见分章错误与修正

| 错误 | 表现 | 修正 |
|------|------|------|
| **章节过碎** | 一章只写一个场景，字数不足 | 将 2-3 个关联场景合并为一章，确保每章有完整的情绪弧 |
| **章节过长** | 一章塞了太多事件，字数超 5000 | 在自然钩子处分拆，确保每章有自己的情绪模板 |
| **模板雷同** | 连续 3+ 章用同一模板 | 替换中间 1-2 章的模板，用场景适配而非模板适配场景 |
| **节奏失衡** | fast 占比超过 50% | 在 fast 章之间插入 medium 过渡章做情绪缓冲 |
| **开场重复** | 连续 3 章以人物醒来/回忆开头 | 交替使用：动作开场→对话开场→环境开场→悬念开场 |
| **无卷末钩子** | 卷尾章没有为下卷蓄力 | 卷尾章最后 200 字必须插入一个悬念/预告/新疑问 |
| **首章无锚点** | 卷首章没有呼应前卷结尾 | 卷首章前 500 字必须承接上卷结尾的状态或悬念 |
