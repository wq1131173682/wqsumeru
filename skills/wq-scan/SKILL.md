## 扫榜分析与竞品拆解

### 触发关键词
扫榜、分析热榜、看看现在什么火、市场调研、竞品分析、拆解XX书、拆解这个链接、分析榜单趋势、看看番茄什么火、看看七猫什么火、热门题材分析、榜单数据分析

### 核心功能
1. **榜单抓取**：从番茄/七猫等平台抓取公开榜单数据
2. **趋势分析**：统计热门题材、套路模式、读者偏好
3. **竞品拆解**：深度拆解标杆作品的结构、人设、钩子、节奏
4. **写作指南生成**：基于趋势+拆解，生成可注入context pack的写作指令

### 与 wq-topic 的区别
- `wq-scan`：数据驱动，从真实榜单/作品中提取市场信息
- `wq-topic`：创意驱动，基于经验和知识生成选题方案
- **配合关系**：scan 的输出（趋势报告）可作为 topic 的输入，提升选题的数据支撑

## 二、榜单抓取规则

### 番茄小说榜单URL模式
```
# 番茄小说Web端榜单页面
https://fanqienovel.com/rank/{榜单类型}
```

### 七猫免费小说榜单URL模式
```
# 七猫Web端榜单页面
https://www.qimao.com/rank/{榜单类型}
```

### 抓取策略
1. **优先抓取web页面**：使用 `webfetch` 抓取榜单页面HTML
2. **解析榜单数据**：从HTML中提取书名、作者、题材、简介、排名等信息
3. **抓取限制**：单次最多抓取榜单前50本，避免过度请求
4. **缓存机制**：同一天对同一榜单的抓取结果缓存到 `.sumeru/research/cache/`

### 抓取失败处理
- 网页抓取失败 → 提示用户手动输入榜单数据
- 页面结构变化 → 记录错误，提示用户反馈

## 四、竞品拆解规则

### 拆解深度

| 字数范围 | 拆解范围 | 说明 |
|----------|----------|------|
| ≤10万字 | 全书拆解 | 完整结构分析 |
| >10万字 | 前3万字 | 聚焦开篇和前期节奏 |

### 拆解维度

#### 1. 结构拆解
| 维度 | 分析内容 |
|------|----------|
| **章节结构** | 每章字数、段落数、对话占比 |
| **节奏曲线** | 冲突-缓解-高潮的分布 |
| **钩子设计** | 每章结尾的悬念/反转类型 |
| **信息密度** | 每章推进的剧情事件数 |

#### 2. 人设拆解
| 维度 | 分析内容 |
|------|----------|
| **主角人设** | 性格特征、金手指、成长曲线 |
| **配角模式** | 主要配角的功能定位、与主角关系 |
| **反派设计** | 反派层次、智商水平、压迫感 |
| **人物关系** | 核心关系网、冲突来源 |

#### 3. 爽点拆解
| 维度 | 分析内容 |
|------|----------|
| **爽点类型** | 打脸/逆袭/升级/揭秘/情感 |
| **爽点频率** | 每N章出现一个爽点 |
| **爽点强度** | 铺垫-爆发的节奏控制 |
| **爽点创新** | 与同类作品的差异化 |

#### 4. 开篇拆解（重点）
| 维度 | 分析内容 |
|------|----------|
| **前100字** | 第一句话的吸引力、冲突启动 |
| **前1000字** | 主角出场方式、金手指暗示 |
| **前3章** | 核心冲突建立、第一个爽点 |
| **钩子设计** | 每章结尾的悬念类型 |

## 五、写作指南生成规则

### 定位
写作指南是**针对当前小说项目**生成的持久化写作指令，只在当前项目创作时使用。

### 生成时机
- 新项目创作规划时（`wq-topic` 或 `wq-worldbuilder` 阶段）
- 用户手动触发：`/wq-scan 生成指南`

### 生成流程
1. **读取项目信息**：从 `.sumeru/project.json` 读取题材、平台、风格
2. **读取扫榜数据**：从 `.sumeru/research/trends.md` 读取趋势报告
3. **读取标杆拆解**：从 `.sumeru/research/benchmarks/` 读取相关题材的拆解
4. **匹配提炼**：从趋势+拆解中提取与当前项目相关的模式
5. **生成指南**：输出 `.sumeru/research/writing-guide.md`

## 六、仿写指南生成规则

### 定位
仿写指南是基于标杆作品拆解，提取**结构/风格/套路模式**的写作指令，用于指导原创内容创作。

**核心原则**：学骨架不学血肉，学模式不学内容。

### 生成时机
- 用户手动触发：`/wq-scan 拆解 《书名》 --imitation`
- 拆解完成后自动生成（当指定 `--imitation` 参数时）

### 生成流程
1. **读取拆解结果**：从 `.sumeru/research/benchmarks/{书名}.md` 读取标杆拆解
2. **提取结构模式**：开篇结构、章节节奏、钩子设计
3. **提取风格特征**：句式、对话、情绪表达、用词习惯
4. **提取套路模式**：金手指、人设、冲突、打脸模式
5. **生成仿写指令**：输出 `.sumeru/research/imitation-guide-{书名}.md`

### 仿写指南格式

```markdown
# 仿写指南：基于《{书名}》

> 本指南提取自《{书名}》的结构/风格/套路模式，用于指导原创内容创作。
> 生成时间：{日期}
> 拆解范围：{全书/前3万字}

## ⚠️ 原创保障声明

仿写时必须确保：
- [ ] 人物名称、外貌、背景**完全原创**
- [ ] 地名、组织名、功法名**完全原创**
- [ ] 具体情节、对话、场景**完全原创**
- [ ] 核心设定有差异化（不能照搬金手指）
- [ ] 只学模式，不学具体内容

任务：深度拆解《{书名}》

拆解范围：{全书/前3万字}

拆解维度：
1. 结构分析：章节字数、段落数、对话占比、节奏曲线
2. 人设分析：主角类型、金手指、配角功能、反派设计
3. 爽点分析：爽点类型、频率、强度、创新点
4. 开篇分析：前100字、前1000字、前3章结构
5. 钩子分析：每章结尾钩子类型、频率

输出格式：按标杆拆解卡片格式输出

重点：
- 提取可复用的模式
- 识别差异化亮点
- 标注避坑提示
```

### 集成点说明

#### wq-topic 集成

- 输出时标注"数据来源：{平台}榜单{日期}"

#### wq-write 集成

## 十二、注意事项

### 数据准确性
- 网页抓取的数据可能存在延迟，需标注抓取时间
- 榜单排名是动态变化的，趋势分析基于抓取时刻的快照
- 拆解分析基于文本内容，可能存在主观判断

### 合规约束
- 拆解仅用于学习分析，不鼓励抄袭
- 引用原文时控制在合理范围内
- 写作指南强调"学习模式"而非"套用内容"

### 资源控制
- 单次抓取最多50本榜单数据
- 单次拆解最多10本书
- 缓存数据24小时后过期
