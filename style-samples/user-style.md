## 使用指南

### 子 Agent 如何使用

1. 读取此文件，分析用户特征
2. 写作时主动模仿样本中的特征
3. 输出后对照此文件自检

### 自检清单

```markdown
## 风格对比自检

### 对照样本检查
- [ ] 用词习惯是否接近样本？（口语化 vs 书面化）
- [ ] 句式特点是否接近样本？（短句/断句 vs 完整/规范）
- [ ] 对话风格是否接近样本？（停顿/改口 vs 完整清晰）
- [ ] 情绪表达是否接近样本？（直接/间接比例）
- [ ] 比喻风格是否接近样本？（个人化 vs 通用化）

### 如果差异太大
- 回到样本，重新分析特征
- 修改"太正确"的部分
- 保留"奇怪"的部分
```
